## Paper names and current implementation

| PDF model/module | Public name or implementation | Location |
| --- | --- | --- |
| OSS-CAEA | OSSCAEA; Python package oss_caea | framework/oss_caea.py |
| Collaborative Attention Module (CAM) | CAM | framework/cam.py |
| Coarse Segmentation Head | CoarseSegmentationHead | framework/coarse_segmentation_head.py |
| Pixel-Semantic Alignment Head (PSAH) | PSAH | framework/psah.py |
| VFM Image Encoder | backbone.vfm (DinoVisionTransformer) | framework/backbone.py |
| Depth Anything V2 | backbone.depth_encoder, loaded from DA V2 pretrained.* weights | framework/backbone.py |
| CLIP Image Encoder | backbone.clip.visual | framework/backbone.py |
| CLIP Text Encoder | backbone.clip.encode_text, shared CLIP weights/cache | framework/backbone.py |
| Linear / GeoText Prompts (GTPs) | CAM.text_proj; geotext_prompts / global_geotext_prompt | framework/cam.py |
| Pixel Decoder | PSAH.pixel_decoder | framework/psah.py |
| Transformer Decoder | PSAH.transformer_decoder | framework/psah.py |
| Cross-Attention / embedding alignment | PSAH.alignment (UnifiedEmbeddingAlignment) | framework/alignment.py |
| Initial queries / position embeddings | PSAH.query_feat / query_embed / decoder_positional_encoding | framework/psah.py |

Locations above are relative to oss_caea/. OSSCAEABackbone is the implementation
wrapper for encoder/CAM/coarse stages, not a separately claimed paper module.
UnifiedEmbeddingAlignment is the query-to-image alignment implementation inside PSAH.
Python identifiers use OSSCAEA or oss_caea because '-' is not a legal identifier.
GTPs are computed text features; they are not an extra independent encoder.

## Current working-tree cleanup

The superseded model implementations, configuration files, compatibility import
module and historical README have been removed. Stale generated bytecode and
installation logs referring to the original project path have also been removed.
README/setup instructions now describe only OSS-CAEA, CAM, Coarse Segmentation
Head and PSAH. The original license and accurate research credit are preserved.

Current configurations select OSSCAEA -> OSSCAEABackbone -> PSAH. CAM and the
coarse head are separate files. The saved-config alias OSSCAEAPSAH still points to
PSAH; this alias contains the current model name and does not create duplicate weights.
Parameter keys and the active network computations remain unchanged.

The cleanup scans source, configuration, tools, tests, documentation and their
filenames. Version-control history and third-party dependency internals are not
rewritten as current project source. Model naming does not establish numerical
or performance equivalence to the paper; implementation decisions are in OSS-CAEA.md.
